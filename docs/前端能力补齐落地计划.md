# 前端能力补齐 - 详细落地计划

## 总体策略

按优先级分 **5 个迭代批次**，每批次聚焦一个功能域，确保可独立交付。

---

## 实施规范

### 文件命名规范
- 页面文件: `web/src/pages/XxxPage.tsx` (PascalCase)
- 替换占位页面时，保留原文件名，替换内容

### 组件规范
- 使用 shadcn/ui 组件库
- 使用 lucide-react 图标
- 遵循现有代码风格（Card/Table/Dialog/Badge 等）

### API 调用规范
- 使用 axios 调用 API
- 统一使用 `/api` 前缀（vite proxy 已配置）
- 错误处理使用 toast

### 路由规范
- 在 `web/src/App.tsx` 中注册路由
- 侧边栏导航在 `web/src/components/` 中配置
