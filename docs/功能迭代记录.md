# 评测系统功能迭代记录

本文档记录从 GitHub 热门评测项目中借鉴的功能。

## 已实现功能

### v1.0 - 基础评测框架
- 技能管理 CRUD
- 数据集管理
- 评测执行
- 标注管理

### v1.1 - shadcn/ui 迁移
- 前端从 Ant Design 迁移到 shadcn/ui + Tailwind CSS
- 响应式侧边栏布局

### v1.2 - 评测功能增强（借鉴 GitHub 热门项目）

#### 借鉴 DeepEval (6k⭐)
- 评测指标体系（答案相关性/忠实度/幻觉/完整性/毒性/偏见）
- G-Eval 通用评测
- 上下文相关性评测

#### 借鉴 Promptfoo (8k⭐)
- 矩阵对比评测（多模型×多prompt×多用例）
- 红队安全扫描（7种攻击插件）
- YAML 声明式测试用例导入

#### 借鉴 Langfuse (27k⭐)
- 评测追踪系统（Trace/Span 调用链路）
- Session 统计

## 计划实现功能

### v1.3 - 本轮迭代（已完成）

#### 1. 合成数据集生成（借鉴 Promptfoo）✅
- 基于 prompt 模板自动生成测试用例
- 支持多 persona 生成
- 边缘情况自动发现
- 可自定义生成数量和指令
- 导出为 YAML 格式

#### 2. RAG 评测指标（借鉴 Ragas）✅
- Context Precision（上下文精度）
- Context Recall（上下文召回）
- Noise Sensitivity（噪声敏感度）
- Answer Context Relevance

#### 3. 对话评测指标（借鉴 DeepEval）✅
- 对话连贯性（Conversational Coherence）
- 对话完整性（Conversational Completeness）
- 对话参与度（Engagement）
- 对话安全性（Safety）
- 话题遵循度（Topic Adherence）

#### 4. Prompt 版本管理（借鉴 Langfuse）✅
- Prompt 版本控制
- 标签管理（draft/staging/production/archived）
- 版本对比
- 状态流转

#### 5. 评测排行榜 ✅
- 多模型性能排名
- 指标对比可视化
- 历史趋势
- 模型对比

### v1.7 - LLM-as-Judge + 护栏 + A/B测试（已完成）

#### LLM-as-Judge 服务（借鉴 Microsoft llm-as-judge + TruLens）✅
- 单点评判（Single Point Judging）
- 对比评判（Pairwise Comparison）
- 参考评判（Reference-Guided Judging）
- 预定义评判 Rubric（有用性/无害性/事实准确性）
- 自定义 Rubric 创建
- 批量评判支持
- 评判置信度评估

#### 输出护栏服务（借鉴 Guardrails AI）✅
- PII 检测与脱敏（邮箱/手机号/身份证/银行卡）
- 毒性内容过滤
- JSON Schema 验证
- 正则表达式验证
- 长度限制验证
- 关键词过滤（支持 any/all 模式）
- 输入注入攻击检测
- 自定义验证器创建
- 验证器启用/禁用控制
- 动作类型：阻断/警告/脱敏

#### A/B 测试服务（借鉴 Langfuse）✅
- 测试创建与配置
- 多版本变体管理
- 流量分配控制
- 测试启动/暂停/完成
- 运行结果记录
- 自动样本量检查
- 结果统计与对比
- 统计显著性计算
- 变体对比分析
