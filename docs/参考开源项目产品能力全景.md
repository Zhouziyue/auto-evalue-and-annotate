## 1. DeepEval — LLM 评测框架

| 属性 | 信息 |
|------|------|
| GitHub | https://github.com/confident-ai/deepeval |
| Stars | 6k+ |
| 语言 | Python |
| 许可证 | MIT |
| 定位 | 面向 LLM 应用的开源评测框架，类似 Pytest 的测试体验 |

### 1.1 核心能力全景

#### 评测指标体系（50+ 指标）

| 指标类别 | 具体指标 | 说明 |
|----------|----------|------|
| **RAG 评测** | Contextual Precision / Recall / Relevancy | 检索质量评估 |
| | Faithfulness | 生成内容是否忠于上下文 |
| | Hallucination | 幻觉检测 |
| | Contextual Relevancy | 上下文相关性 |
| **对话评测** | Answer Relevancy | 答案相关性 |
| | Conversational Relevancy | 多轮对话相关性 |
| | Knowledge Retention | 知识保持能力 |
| | Tool Correctness | 工具调用正确性 |
| **Agent 评测** | Task Completion | 任务完成度 |
| | Tool Usage Accuracy | 工具使用准确性 |
| | Trajectory Accuracy | 轨迹正确性 |
| | Agent Goal Accuracy | 目标达成度 |
| **安全评测** | Toxicity | 毒性检测 |
| | Bias | 偏见检测 |
| | PII Detection | 个人信息泄露检测 |
| | Jailbreaking Detection | 越狱攻击检测 |
| **质量评测** | G-Eval | 通用 LLM-as-Judge 评分 |
| | Summarization Quality | 摘要质量 |
| | Question Answering | 问答质量 |
| | Prompt Alignment | Prompt 对齐度 |
| **多模态评测** | Image Caption Quality | 图像描述质量 |
| | Text-to-Image | 文生图质量 |
| | Multimodal Relevancy | 多模态相关性 |
| **传统指标** | BLEU / ROUGE / BERTScore | 文本相似度 |
| | Exact Match | 精确匹配 |
| | F1 Score | F1 分数 |

#### 三种评测模式

| 模式 | 适用场景 | 说明 |
|------|----------|------|
| **端到端评测** | 简单 API / 聊天机器人 | 黑盒测试，输入→输出→评分 |
| **组件级评测** | Agent / 多步应用 | 对单个 span/tool/retriever 分别评分 |
| **轨迹评测** | 长链路 Agent | 评估完整执行路径的质量 |

#### 核心功能

| 功能 | 说明 |
|------|------|
| **Pytest 集成** | 使用 `pytest` 风格编写评测用例，无缝集成 CI/CD |
| **合成数据生成** | 自动生成边界 case 数据集，覆盖难收集场景 |
| **回归检测** | 跨版本对比评测结果，自动识别退化项 |
| **LLM-as-Judge** | 内置 G-Eval 等 LLM 评判方法，可自定义评判标准 |
| **Tracing** | 运行时记录 Agent 的每一步执行，支持组件级分析 |
| **Confident AI 集成** | 可选连接云端 Dashboard，支持团队协作和监控 |
| **DeepTeam 红队** | 安全测试框架（DeepEval 生态），用于 LLM 红队扫描 |
| **Vibe Coding 支持** | 支持 Cursor/Claude Code/Codex 等 AI 编码工具集成 |

#### 评测对象支持

| 对象 | 支持情况 |
|------|----------|
| AI Agent | ✅ 端到端 + 轨迹 + 组件 |
| RAG Pipeline | ✅ 检索 + 生成分别评测 |
| Chatbot | ✅ 多轮对话评测 |
| MCP 系统 | ✅ 单轮/多轮交互评测 |
| 多模态应用 | ✅ 图像/文本联合评测 |
| 结构化输出 | ✅ JSON/Schema 验证 |

### 1.2 本项目借鉴点

- ✅ 评测指标体系（已实现：忠实度、幻觉、毒性、相关性、完整性）
- ✅ G-Eval 通用评分（已实现）
- ✅ 对话评测（已实现）
- ⚠️ Agent 轨迹评测（部分实现）
- ❌ 合成数据生成（待实现）
- ❌ MCP 评测（待实现）

## 2. Promptfoo — LLM 测试与安全框架

| 属性 | 信息 |
|------|------|
| GitHub | https://github.com/promptfoo/promptfoo |
| Stars | 8k+ |
| 语言 | TypeScript/Node.js |
| 许可证 | MIT |
| 定位 | 开源 CLI + 库，用于 LLM 评测、红队测试和安全扫描 |

### 2.1 核心能力全景

#### 评测能力

| 功能 | 说明 |
|------|------|
| **矩阵评测** | 行=测试用例 × 列=Prompt/模型，生成全量对比矩阵 |
| **声明式 YAML 用例** | 无需写代码，YAML 定义 prompt + 变量 + 断言 |
| **多 Provider 支持** | OpenAI / Anthropic / Azure / Google / HuggingFace / Ollama / 自定义 API |
| **50+ Provider** | 支持 50+ LLM 提供商，包括本地模型 |
| **变量替换** | 模板变量 `{{variable}}` 批量生成测试用例 |
| **断言系统** | 20+ 断言类型：contains / regex / json / llm-rubric / similar / cost / latency |
| **LLM 评判断言** | 使用 LLM 作为评判标准（model-graded） |
| **缓存与并发** | 内置缓存、并发执行、实时热重载 |
| **Web UI** | 可视化查看评测结果，支持对比和筛选 |

#### 红队安全测试

| 功能 | 说明 |
|------|------|
| **自动化红队** | 自动生成攻击性 prompt，测试 LLM 安全边界 |
| **漏洞扫描** | 检测注入攻击、越狱、PII 泄露、有害内容等 |
| **自定义策略** | 支持自定义安全策略和风险规则 |
| **风险报告** | 生成安全风险报告，含漏洞等级和分类 |
| **合规检查** | 检查模型输出是否符合安全合规要求 |
| **多轮攻击** | 支持多轮对话式攻击测试 |
| **OWASP 覆盖** | 覆盖 OWASP LLM Top 10 安全风险 |

#### 工程化能力

| 功能 | 说明 |
|------|------|
| **CI/CD 集成** | 原生支持 GitHub Actions / GitLab CI / Jenkins |
| **语言无关** | 支持 Python / JavaScript / 任何语言的自定义 Provider |
| **分享协作** | 内置分享功能，生成在线查看链接 |
| **版本对比** | 跨版本评测结果对比 |
| **数据集管理** | 支持导入/导出测试数据集 |
| **合成数据** | 自动生成合成测试数据 |

### 2.2 本项目借鉴点

- ✅ 矩阵评测思路（已实现：多模型对比评测）
- ✅ YAML 用例（已实现：声明式评测配置）
- ✅ 红队扫描（已实现：安全评测服务）
- ✅ 合成数据（已实现：AI 生成评测用例）
- ⚠️ CI/CD 集成（部分实现）

## 3. Langfuse — LLM 工程平台

| 属性 | 信息 |
|------|------|
| GitHub | https://github.com/langfuse/langfuse |
| Stars | 27k+ |
| 语言 | TypeScript (全栈) |
| 许可证 | MIT (核心) / EE (企业版) |
| 定位 | 开源 LLM 工程平台：追踪 + 评测 + Prompt 管理 + 可观测性 |

### 3.1 核心能力全景

#### 可观测性与追踪

| 功能 | 说明 |
|------|------|
| **应用追踪** | 记录每个请求的完整生命周期：prompt → 模型响应 → 工具调用 |
| **嵌套观测** | Trace → Observation → Span → Generation 层级结构 |
| **Token/成本追踪** | 精确追踪每次 LLM 调用的 token 用量和成本 |
| **延迟监控** | 追踪每个步骤的延迟，识别性能瓶颈 |
| **Session 追踪** | 将多个 trace 关联到同一用户会话 |
| **Agent 图可视化** | 可视化 Agent 的执行图和调用链 |
| **元数据标记** | 支持自定义 metadata 附加到 trace |
| **异步批量** | SDK 异步发送，不影响应用响应延迟 |

#### 评测体系

| 功能 | 说明 |
|------|------|
| **LLM-as-Judge** | 内置 LLM 评判评测，支持自定义评判标准 |
| **用户定义评分** | 支持人工标注和用户反馈评分 |
| **自定义评分器** | 可编程自定义评分逻辑 |
| **实验管理** | 基于数据集运行实验，对比不同 prompt/模型效果 |
| **数据集管理** | 创建和管理评测数据集 |
| **A/B 测试** | 对比不同 prompt 版本或模型的效果 |

#### Prompt 管理

| 功能 | 说明 |
|------|------|
| **版本控制** | Prompt 版本管理，支持回滚 |
| **标签系统** | 通过标签管理不同环境的 prompt（production/staging） |
| **解耦部署** | Prompt 更新无需代码部署，非技术人员可直接修改 |
| **客户端缓存** | SDK 本地缓存，零延迟获取 prompt |
| **Playground** | 在线调试和测试 prompt |
| **关联追踪** | Prompt 版本与 trace 关联，分析性能变化 |

#### 数据分析与监控

| 功能 | 说明 |
|------|------|
| **自定义仪表盘** | 可配置成本、延迟、质量等维度的看板 |
| **告警** | 指标超阈值自动告警 |
| **成本分析** | 按模型/用户/时间维度分析 LLM 使用成本 |
| **质量监控** | 持续监控应用质量分数趋势 |

#### 集成生态

| 集成 | 说明 |
|------|------|
| **LangChain** | 原生 callback 集成 |
| **LlamaIndex** | 原生 callback 集成 |
| **OpenAI SDK** | Monkey-patch 集成 |
| **Vercel AI SDK** | 原生集成 |
| **LiteLLM** | 代理层集成 |
| **Mistral / Cohere** | 原生集成 |
| **API 完整** | RESTful API 支持所有操作 |

#### 部署方式

| 方式 | 说明 |
|------|------|
| **Cloud (SaaS)** | 官方托管，开箱即用 |
| **Self-hosted** | Docker / Kubernetes 自托管 |
| **开源核心** | 核心功能完全开源 |

### 3.2 本项目借鉴点

- ✅ A/B 测试（已实现）
