# 评测系统架构文档

## 系统概述

这是一个面向技能/Agent 的自动化评测平台，支持"跑 -> 评 -> 标 -> 修 -> 验"全链路闭环。系统从 v1.0 迭代至 v1.18，累计实现 **48 个核心服务模块**，覆盖评测系统全生命周期。

## 技术栈

- **后端**: NestJS 10 + TypeScript
- **前端**: React 18 + Vite 5 + shadcn/ui + Tailwind CSS v3
- **数据库**: SQLite + Prisma ORM
- **API 风格**: RESTful
- **编译**: TypeScript + SWC（跳过类型检查）

## 开发规范

1. **服务文件**: 所有服务文件使用 `// @ts-nocheck` 跳过类型检查
2. **编译命令**: `& "C:\Program Files\nodejs\node.exe" "node_modules\typescript\bin\tsc" --noEmit`
3. **Git 命令**: `& "C:\Program Files\Git\bin\git.exe"`
4. **模块注册**: 新服务必须在 `eval.module.ts` 的 providers 和 exports 中注册
5. **API 端点**: 在 `eval.controller.ts` 中添加，路由前缀 `/api/eval`
