# 技能评测系统方案

## 系统定位
面向技能/Agent的自动化评测平台，支持"跑 -> 评 -> 标 -> 修 -> 验"全链路闭环。

## 技术选型建议
- 前端：React + Vite + Ant Design（看板/流水线编排）
- 后端：Node.js (Nest.js) 或 Python (FastAPI)
- 数据库：PostgreSQL（结构化数据）+ Redis（任务队列）
- 任务调度：Bull (Node) 或 Celery (Python)
- 文件存储：MinIO / OSS（评测产物、日志）

## 核心模块设计

### 模块一：评测数据集管理
- 数据集 CRUD，支持多数据集隔离
- 用例分级：简单/中等/困难，按技能类型分类
- 用例结构：输入(prompt/上下文) + 期望输出 + 评测维度标签
- 版本管理：数据集快照，支持回溯
- Bad Case 沉淀：线上问题一键转入数据集
- 数据导入/导出：JSON/CSV/Excel 批量操作
- **评测集 AI 生成**：
  - 输入一个问题/场景，AI 自动生成 3 个候选标准答案（不同风格/角度）
  - AI 智能优选：系统自动从 3 个候选中推荐最优答案（基于准确性、完整性、表达质量打分）
  - 人工选择与修正：标注员可从 3 个候选中选一个，也可以手动编辑/重写，最终确认标准答案
  - 批量生成：支持批量输入问题列表，一次性生成整个评测集
  - 生成记录：保留每次生成的候选答案和选择/修改历史，可追溯

### 模块二：智能体自动接入与适配层（HTTP + SSE）
- 协议类型：仅支持 HTTP 请求 + SSE 流式响应，不做 WebSocket/gRPC 等扩展
- SSE 响应解析器：不同智能体 SSE 返回格式各异（如 data: {"content": ...} vs data: {"delta": ...}），提供可配置的 SSE 事件解析模板，通过 JSONPath / 正则提取最终文本
- 智能体注册中心：管理待评测的智能体，配置接入地址、认证方式（API Key / OAuth / Token）、响应格式模板
- 自动探测：输入智能体地址后，自动探测 SSE 响应格式，推荐解析模板
- 请求构造器：可视化配置 HTTP 请求体模板（支持变量注入，如 {{input}}、{{context}}）
- 多轮会话管理：维护 session 状态，支持有状态的多轮对话评测
- 连接池与限流：对同一智能体复用连接，支持 QPS 限流，避免打爆下游

### 模块三：自动化执行引擎
- 执行器：基于适配层并发跑用例，支持超时控制、重试机制
- 执行产物：原始输出（含原始 SSE 流）、解析后文本、耗时、token消耗、中间步骤（Agent思考链）
- 环境隔离：每次执行独立上下文，避免污染
- 流式 vs 非流式：同时支持流式（SSE）和非流式两种模式，流式模式可记录首 token 延迟（TTFT）

### 模块四：多维度评测引擎
- 规则评测：精确匹配、正则、关键词、格式校验
- AI 评测：用 LLM 对输出打分（准确性/完整性/相关性/安全性）
- 指标评测：响应时间、token 用量、调用次数
- 多轮评测：模拟多轮对话，评测上下文保持、状态管理、意图切换
- 评测维度可配置：每个技能/数据集可绑定不同评测维度和权重

### 模块五：双标注体系（人工 + AI）
- AI 预标注：系统自动给出初步评分和标注建议
- 人工复核：标注员在 AI 标注基础上修改确认
- 标注一致性：计算人工与 AI 标注的吻合度（Kappa系数）
- 标注任务分配：支持按技能/数据集分配给不同标注员
- 标注仲裁：多人标注不一致时，支持仲裁流程

### 模块六：AI 魔法修复
- 问题诊断：AI 分析 bad case 根因（prompt问题/模型能力/知识缺失）
- 修复建议：自动生成修复方案（改写 prompt/补充知识/调整参数）
- 一键修复：应用修复方案后自动重跑验证
- 修复记录：修复前后对比，修复成功率统计

### 模块七：评测报告与可视化看板
- 总览看板：技能健康度、评测通过率、趋势图
- 技能详情页：各维度得分雷达图、历史趋势、bad case 列表
- 版本对比：两个版本的评测结果 diff，高亮退化项
- 导出报告：PDF/HTML 格式导出
- **AI 智能统计分析**（评测完成后用大模型分析）：
  - 失败模式聚类：大模型自动分析 bad case，归纳失败原因类别（如理解偏差、知识缺失、格式错误等）
  - 能力画像：基于评测结果，用大模型生成技能的能力画像（擅长什么、弱项在哪）
  - 改进建议：大模型根据评测结果生成针对性的优化建议（优先级排序）
  - 对比分析：多版本/多技能评测结果，大模型生成对比洞察报告
  - 自然语言总结：每次评测自动生成一段可读性强的评测总结（替代纯数字报表）

### 模块八：回归测试与版本对比
- 版本快照：每次评测结果绑定技能版本号
- 自动回归：技能更新后自动触发回归评测流水线
- 退化告警：关键指标下降超过阈值时通知（钉钉/飞书/邮件）
- 对比视图：逐用例对比新旧版本输出差异

### 模块九：评测流水线编排
- 可视化编排：拖拽式配置评测流程节点
- 预置模板：快速评测、完整评测、回归评测等常用模板
- 节点类型：数据选择 → 执行 → 评测 → 标注 → 修复 → 再验证
- 定时触发：支持 cron 表达式定时跑评测
- 流水线状态：实时查看每个节点的执行进度

## 数据模型（核心实体）

| 实体 | 说明 |
|------|------|
| Skill | 待评测的技能/Agent |
| AgentEndpoint | 智能体接入配置（地址/认证方式/SSE响应格式模板） |
| ProtocolAdapter | 协议适配器定义 |
| Dataset | 评测数据集 |
| TestCase | 评测用例（属于某个Dataset） |
| EvalRun | 一次评测执行记录 |
| EvalResult | 单条用例的评测结果 |
| Annotation | 标注记录（人工/AI） |
| FixRecord | AI修复记录 |
| Pipeline | 评测流水线定义 |
| PipelineInstance | 流水线执行实例 |
| SkillVersion | 技能版本快照 |

## 实施路径（分三期）

### 第一期：核心闭环（MVP）
- 智能体接入适配层（HTTP + SSE协议适配） + 数据集管理 + 自动化执行 + 规则/AI评测 + 基础报告
- 目标：能接入智能体（HTTP+SSE），跑通"导入数据 -> 跑技能 -> 出评测结果"的完整流程

### 第二期：标注与修复
- 双标注体系 + AI魔法修复 + 多轮对话评测 + 版本对比
- 目标：评测结果可信赖，修复链路打通

### 第三期：工程化
- 可视化看板 + 流水线编排 + 回归测试 + 告警通知
- 目标：生产级可用，团队协作，自动化运维

## 项目结构建议（以 Nest.js 为例）
```
skill-eval-system/
  apps/
    web/              # React 前端
    server/           # Nest.js 后端
  packages/
    shared/           # 前后端共享类型定义
    eval-engine/      # 评测引擎核心逻辑
    executor/         # 技能执行器
    adapter/          # 智能体协议适配层
    annotation/       # 标注模块
    fixer/            # AI修复模块
  docker-compose.yml  # 本地开发环境
```
